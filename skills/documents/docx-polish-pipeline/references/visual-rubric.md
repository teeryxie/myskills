# Visual Rubric

## What To Check

Review generated pages like a document production editor, not like a content summarizer.

## First Page

Pass when:

- the title is immediately legible
- the visual hierarchy is obvious
- the page does not look empty, broken, or half-finished
- core metadata is grouped cleanly

Fail when:

- the bottom half is visibly empty without intent
- a table starts but does not visually land
- the page looks like a markdown export rather than a formal file

## Table Pages

Pass when:

- headers, numbers, and descriptions align naturally
- the table looks filled and intentional
- row density is readable without appearing skeletal

Fail when:

- the table appears as an empty frame
- actual content falls outside the table visual area
- totals or important figures float without anchoring

## Body Pages

Pass when:

- headings, paragraphs, and spacing form a clear reading rhythm
- paragraphs do not become dense walls of text
- page breaks feel intentional

Fail when:

- headings wrap awkwardly because they are too long
- major sections start at the very bottom of a page
- there is obvious imbalance between huge blank zones and dense text blocks

## Delivery Decision

- `internal-ready`: usable for internal sharing with only minor cosmetic issues
- `external-ready`: acceptable for customer-facing or formal external delivery
- `revise-required`: visible draft artifacts remain; revise before sharing
